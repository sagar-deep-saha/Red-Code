Download `RedCode-Setup.exe` below. Existing installs with the updater will find this release automatically.

### API client

- Create collections and save API requests as persistent editor tabs.
- Restore temporary request tabs across editor and app restarts, and duplicate the active request.
- Edit base URLs, save named profiles, and switch saved endpoints from a dropdown.
- Use the new transparent, theme-aware API Activity Bar icon.

### Git graph

- Browse commits in aligned branch, graph, and message columns.
- Optionally show commit-author avatars; Gravatar lookup is disabled by default.

### Workbench

- See the Red Code watermark in the editor background across themes.
- Updated the Windows installer wizard artwork with the Red Code mark.

### Platforms

- `1.147.5` is a Windows x64 build. The plan to add macOS and Linux packages was dropped after
  this release: Red Code stays on Windows, and `1.147.6` onwards ships Windows x64 and arm64 with a
  `SHA256SUMS` file. No macOS or Linux package has been or will be published.
